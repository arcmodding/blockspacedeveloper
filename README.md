# BlockSpace

A clean Next.js starter for an original game-discovery platform inspired by familiar sandbox-game layouts. It does not use Roblox branding, names, logos, or assets.

## Deploy to Vercel

1. Upload these files to a new GitHub repository.
2. Import that repository into Vercel.
3. Vercel should detect Next.js automatically.
4. Deploy.

The project intentionally does not include a package-lock.json so Vercel can install the declared dependency versions cleanly.
